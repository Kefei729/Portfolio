The Concept

Designed and modeled a wheeled cactus pot in Blender. The goal was to create a quirky, playable character for a game environment. After modeling, I imported the character into Unreal Engine 5 to create an interactive experience.

Tutorial Reference

The Process

I started by modeling the base mesh using simple primitives in Blender.

In Unreal Engine 5, I implemented a Blueprint-based game logic which includes point-collection mechanics and animation controls for the wheeled movement.
