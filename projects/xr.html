The Concept

This project bridges the gap between literature and nature through immersive XR technologies, inspired by the poetry of Friedrich Hölderlin. The AR component, developed in Unity using Lightship’s Object Detection, overlays lyrical elements onto real-world flora, creating a "poetic layer" over reality. To deepen the emotional resonance, the VR experience (built in Unreal Engine 5) transports users into a surreal, atmospheric landscape where they can interact with the poem's imagery in a fully immersive 3D space.

The Process

AR Development & UI/UX (Unity):
As the lead developer for the frontend and AR integration, I prototyped the interface in Figma and implemented the application in Unity. I utilized the Niantic Lightship SDK to set up the Object Detection functionality. To achieve this, I went through the complete workflow of recording and processing custom playback datasets to configure and test the detection model on mobile devices. To improve the user experience, I also designed an initial onboarding tutorial to instruct users on how to properly scan objects when they first launch the application.

VR Environment & Interaction (Unreal Engine 5):
To expand the project's scope, I conceptualized and built a complementary VR environment in Unreal Engine 5. I focused on Atmospheric Storytelling by combining volumetric lighting with spatial audio. Regarding the gameplay, I implemented VR Interaction Logic that allows users to "trigger" lines of poetry and manipulate lighting effects using motion controllers, transforming the reading experience into an active exploration.
