Overview

A collaborative XR project bridging literature and technology. This project combines an Augmented Reality (AR) mobile app with a Virtual Reality (VR) experience to interpret Friedrich Hölderlin's poetry. The system leverages Unity for real-world object detection and Unreal Engine 5 for an immersive, atmospheric virtual landscape, offering users two distinct ways to engage with the text.

Development Process

  • UI/UX Prototyping & Frontend: The user interface was initially prototyped in Figma to define the interaction flow, followed by a complete frontend implementation in Unity.
  • AR Object Detection Pipeline: Utilizing the Niantic Lightship SDK, the detection functionality was established by recording and processing custom playback datasets to configure and test the model's accuracy on mobile devices.
  • User Onboarding Design: To address scanning complexities, an initial onboarding tutorial was designed and integrated, guiding users through the correct object scanning process upon startup.
  • Poetic Visualization: Built in Unreal Engine 5, the VR environment serves as a visual interpretation of the poem. Volumetric lighting and spatial audio define the atmosphere, providing users with a sensory context to better comprehend the literary work.
  • VR Interaction Logic: Motion controller mechanics were programmed to allow users to trigger poetic lines and manipulate environmental lighting dynamically, transforming passive reading into active exploration.
